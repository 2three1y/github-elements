GitHub Elements playground

All 17 of GitHub's open-source web components, each with a live demo you can try with a keyboard or screen reader. I'm using it to pick which ones fit Looscid.

Anything that normally talks to a server is faked inside this page. Nothing you type is sent anywhere.

auto-check

Checks what you type against a server, like seeing if a username is free, when you leave the field.

Type a name, then press Tab to leave the field. Taken names: hubot, octocat, admin, looscid.

Nothing checked yet.

Screen reader notes

  • The check runs when focus leaves the field (after the first error, it rechecks as you type).
  • It only sets the field's validity. It doesn't announce anything by itself, so this demo writes the result in text linked to the field and sends it to the page's one status message.
  • The input is a normal text field; the component just turns off autocomplete and spellcheck on it.

auto-complete

A text field that shows suggestions from a server as you type, and you pick one.

    Nothing picked yet.

    Screen reader notes

    • The field becomes a combobox with a listbox popup. Up and Down arrows move through options, Enter picks, Escape closes.
    • The highlighted option is tracked with aria-activedescendant, so focus stays in the field while you arrow.
    • It can add its own polite live region that reads out the number of results. I left that out to keep one status message per page, and this demo announces the count there instead.
    • Has a real Clear button (keyboard reachable) instead of the browser's mouse-only x. Gotcha: it names that button "clear:" plus the field's label, but it finds the label by the input's name, not its id. Without a matching name and a label id, VoiceOver just hears "clear:".

    clipboard-copy

    A button that copies text to the clipboard.

    Copy

    Screen reader notes

    • It isn't a real button element, but it gives itself role button and a tab stop, and Enter or Space activates it.
    • It doesn't say anything after copying. This demo announces "Copied" through the page's status message.

    details-dialog

    A pop-up dialog built on a disclosure (details and summary), so it opens without much script.

    Open the dialog

    Hi from the dialog

    Focus moved in here. Tab stays inside until you close it.

    Screen reader notes

    • When it opens it gets role dialog and aria-modal, moves focus inside and traps Tab there. Escape or the Close button closes it and focus goes back to the opener.
    • The opener is a summary, so VoiceOver may say "collapsed" or "expanded" on it like a disclosure.

    details-menu

    A drop-down menu built on a disclosure (details and summary).

    Favorite robot: None

    Screen reader notes

    • Opening it (Enter or Space on the summary) moves focus to the first item. Up and Down arrows move, Enter picks, Escape closes and returns focus.
    • The summary gets aria-haspopup. Picked items get aria-checked, and the summary text updates to the choice.

    file-attachment

    Accepts files dropped on it or picked with a file input, and hands them to your code to upload.

    Nothing is uploaded. The demo only lists the names.

    Chosen files

    • No files yet.

    Screen reader notes

    • The drop area itself has no role or keyboard support. The file input inside it is the keyboard and screen reader way in, and it works like any file picker.
    • It doesn't announce anything. This demo lists the files and announces the count.

    g-emoji

    Wraps an emoji so old browsers that can't draw it get an image instead, and can change skin tone.

    👋 🚀 💜

    Skin tone for the wave:

    Screen reader notes

    • On modern browsers it does nothing visible; the emoji is just text, so VoiceOver reads its normal name ("waving hand").
    • The image fallback only kicks in on browsers without emoji support, and needs image files. This demo has none, so the fallback isn't shown.
    • Changing tone swaps the character, so the new name (like "waving hand, medium skin tone") is read when you move to it.

    image-crop

    Lets you drag or nudge a square crop box over an image and gives back x, y, width and height.

    With the crop box focused: arrow keys move it, minus and equals make it smaller or bigger, Escape resets.

    Crop: not moved yet.

    Screen reader notes

    • The component isn't focusable by itself, even though it listens for keys. This demo adds a tab stop and a label so keyboard cropping works.
    • Arrow keys move the box 1 pixel per press (slow), minus and equals resize by 10, Escape resets.
    • The image inside has empty alt text and the box has no role, so a screen reader gets nothing about the crop on its own. This demo writes the numbers below the image and announces them once you stop moving.
    • On iPhone with VoiceOver and no keyboard, dragging is the only way to move it. Limited for blind users.

    include-fragment

    A placeholder that loads a piece of HTML from a URL and swaps itself out for it.

    Screen reader notes

    • Its loading text is whatever you put inside. When the HTML arrives it replaces itself, and focus doesn't move.
    • It doesn't announce the new content. This demo announces "Fragment loaded"; the new text sits right after the button.

    markdown-toolbar

    A row of formatting buttons (bold, link, list…) that insert Markdown into a text box.

    Bold Italic Heading Quote Code Link Bulleted list Numbered list Task list Mention

    Screen reader notes

    • The toolbar gets role toolbar and is one tab stop: Left and Right arrows move between buttons, Home and End jump to the ends.
    • Each item gets role button. Pressing one changes the text box but doesn't announce what changed, so you'd check the text yourself.

    relative-time

    Shows a date as "5 minutes ago" or "in 2 days" and keeps it up to date.

    • Five minutes back: January 1, 2026
    • Three hours back: January 1, 2026
    • Two days back: January 1, 2026
    • Ten minutes ahead: January 1, 2026
    • As a duration: January 1, 2026

    Screen reader notes

    • In Chrome's accessibility tree the visible text (like "5 minutes ago") is exposed as normal text, and the element also gets the full date as its name from its title. Some screen readers may read the date instead of, or as well as, "5 minutes ago".
    • It updates itself as time passes, quietly, with no announcements.
    • The full date is in a title attribute, which VoiceOver usually doesn't read. Without JavaScript the text inside the tag (here the full date) shows instead.

    remote-input

    Sends what you type to a server and puts the HTML it sends back on the page, like a live Markdown preview.

    Preview:

    Nothing yet.

    Screen reader notes

    • The preview is updated quietly; nothing is announced (on purpose, it would talk on every keystroke). Move to the preview to read it.
    • It adds a loading attribute while waiting, which you could use for a visual spinner.

    tab-container

    Accessible tabs: a row of tab buttons that switch between panels.

    Notes panel. Short thoughts go here.

    Replies panel. Conversations go here.

    Zaps panel. Tips go here.

    Screen reader notes

    • Follows the standard tabs pattern: one tab stop for the tab row, Left and Right arrows (and Home and End) switch tabs right away, then Tab moves into the panel.
    • Tabs report "selected" and position (like "tab, 2 of 3").

    task-lists

    Checkbox to-do lists (like on GitHub) that report check changes and can be reordered by dragging.

    Screen reader notes

    • The checkboxes are normal checkboxes: Space toggles them, and the component fires an event (this demo announces "checked" or "unchecked").
    • Reordering is drag only. The drag handles it adds are hidden from screen readers and there's no keyboard way to move items. Limited.
    • I wrapped each item's text in a label so each checkbox has a name. The component still worked.

    text-expander

    Pops up suggestions when you type a trigger like @ or : in a text box, for mentions and emoji.

    Screen reader notes

    • The text box becomes a combobox while the menu is open. Up and Down arrows move, Enter or Tab inserts, Escape closes.
    • It does not announce how many suggestions there are, and VoiceOver support for aria-activedescendant inside a textarea can be patchy. Worth testing on your phone.

    typing-effect

    Types out lines of text letter by letter, like someone typing.

    |

    Screen reader notes

    • The text appears letter by letter but isn't a live region, so VoiceOver doesn't read each letter. Read it after it finishes.
    • If Reduce Motion is on, the text just appears at once.
    • The blinking cursor is hidden from screen readers in this demo.
